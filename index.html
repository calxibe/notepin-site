Features

Everything You Need

From quick capture to resilient sync, NotePin keeps every note tied to the page that matters.

📌

Save Selected Text with Its Source

Highlight text on any website, save it through the context menu, and keep the current page attached automatically.

  • Select text on any website and right-click Save to NotePin
  • NotePin opens with the selected text already prefilled as the note
  • When you save, the note keeps the current page URL and domain automatically
  • You can still save notes for the current page or any URL you enter manually
  • Optional in-page stickies show matching notes directly on supported websites
  • Toolbar badge shows how many notes exist for the current site
🎨

Edit Fast, Organize Visually

Make notes readable at a glance and keep important ones easy to reach.

  • 8 note colors with matching form accents
  • Inline edit text, URL, and color without leaving the list
  • Pin or star important notes so they stay at the top
  • Bulk color, pin, unpin, export, delete, and duplicate cleanup in fullscreen
  • Copy note text from any note card or from the view modal
  • Undo single-note deletes from a 5-second toast
📂

Popup + Fullscreen Workflow

Use a compact popup for quick capture or a fullscreen workspace when you need more control.

  • Search-first popup layout with a Current Site checkbox
  • Fullscreen workspace with manual URL entry, domain/color filters, and bulk actions
  • 6 sort options: Created, Updated, A–Z / Z–A
  • Domain sidebar with counts, expand/collapse all, and mobile drawer behavior
  • Fullscreen help icon opens an in-app FAQ with a one-click Feedback & Issues button
  • Fullscreen layout adapts cleanly on narrower screens
🔍

Search & Filters That Help

Find notes by what they say, where they came from, or how you grouped them.

  • Search across note text, URL, and domain
  • Fullscreen domain filters include note counts and No Domain entries
  • In-page sticky overlays include a compact search filter for larger note sets
  • Search no-results states echo the exact term you typed
  • Popup filter choice plus fullscreen search, sort, and domain state are remembered
⚙️

Reliable Sync & Recovery

Sync across devices without quietly overwriting data when Chrome sync is incomplete.

  • Chunked browser sync storage stays within quota limits
  • Revision-checked saves protect against popup/fullscreen write conflicts
  • Warning banner blocks writes when sync returns an incomplete snapshot
  • Settings can still open with cached values when background sync is temporarily unavailable
  • Real-time refresh pulls in note changes from other extension views
  • JSON export/import supports backup and migration
🔒

Privacy and Accessibility

Keep URLs cleaner, keep the UI keyboard-friendly, and keep your data inside the browser.

  • Interface follows your browser language with built-in English, Spanish, Brazilian Portuguese, French, German, Japanese, and Norwegian Bokmål support
  • Strip query strings or hash fragments from saved note URLs
  • Bare web addresses get https:// added automatically before validation
  • Unsupported URL schemes are ignored instead of being saved
  • No note data is sent to third-party servers
  • Accessible labels, pressed states, and live status announcements throughout
  • Minimal permissions: storage, activeTab, contextMenus, scripting — plus website access you grant only if you turn on in-page sticky notes
💡

More Features

NotePin also includes 2,000-character notes with a live counter, auto-save drafts, hover-friendly timestamps, automatic dark mode, inline copy buttons, browser-language UI support, smarter search empty states, optional site stickies, and fullscreen domain or color filtering that can also group notes without a domain.
