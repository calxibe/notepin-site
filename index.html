Features

Everything You Need

From quick notes to full organization—NotePin keeps your ideas tied to the pages that matter.

📌

Contextual Notes

Save notes linked to specific web pages. Always find your notes right where you left them.

  • Notes store URL, domain, color, and created / edited timestamps
  • Create notes for the current page or manually enter any URL
  • Filter by All Notes, Current Site, or Search
  • Right-click selected text to open NotePin with the note prefilled
  • Badge count shows notes for the current domain
🎨

8 Note Colors

Organize your notes visually with a color that matches the context.

  • Red, Yellow, Blue, Green, Purple, Orange, Pink, Teal
  • Color accent on the note form matches your pick
  • Change colors inline while editing
  • Border preview updates in real-time
📂

Two Powerful Views

Switch between a quick popup and a full-screen tab for deeper note management.

  • Popup (360×600) for quick access from the toolbar
  • Fullscreen tab with domain sidebar, sorting, and manual URL entry
  • 6 sort options: Created, Updated, A–Z / Z–A
  • Domain filtering with note counts and expand / collapse all
🔍

Search & Filter

Find any note instantly across text, URLs, and domains.

  • Searches across note text, URL, and domain
  • Debounced input (300ms) for smooth filtering
  • Domain sidebar with filter input (fullscreen)
  • Remembers popup filters plus fullscreen sort, search, and domain state
⚙️

Smart Storage

Notes sync across devices with intelligent chunked storage that respects browser sync quotas.

  • Browser sync storage for cross-device access
  • Chunked JSON storage (7,500 bytes per chunk)
  • Export/Import notes as JSON
  • Backward-compatible migration from legacy format
  • Real-time refresh when notes change in another extension view
🔒

100% Privacy First

Your notes stay on your machine and your browser sync profile. No external servers involved.

  • Everything runs client-side in your browser
  • No note data is sent to third-party servers
  • No analytics or usage tracking inside the extension
  • Minimal permissions: storage, activeTab, contextMenus
