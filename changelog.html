Changelog

All notable changes to NotePin are documented here.

v1.0.4 Update April 5, 2026

✨ Added

  • Privacy Settings: You can now strip query strings and hash fragments from newly saved note URLs

🔄 Changed

  • Context Menu Flow: Saving selected text from the page context menu now opens NotePin with the text prefilled so you can review it before saving
  • Shared UI Refresh: Popup and fullscreen now share a more polished UI layer, and fullscreen works better on narrower screens
  • Save and Sync Feedback: Save and sync handling is more reliable and now surfaces clearer non-blocking feedback when sync has problems

🐛 Fixes

  • Source URL Retention: Notes started from the page context menu now keep the original page URL and domain when saved from the popup
  • URL Validation: Invalid or unsupported page URLs are no longer attached to new notes or context-menu prefills
  • Accessibility: Improved keyboard and screen-reader support for note controls and status announcements
  • Mobile Layout and Startup: Fixed mobile fullscreen and popup issues affecting viewport sizing, header and footer layout, scrolling, and first-load stability
  • Search Control Borders: Popup and fullscreen search inputs now render cleanly as a single control
v1.0.3 Update April 2, 2026

✨ Added

  • Microsoft Edge Release: NotePin is now available on Microsoft Edge Add-ons

🐛 Fixes

  • Sync Reliability: Improved sync recovery helps preserve existing notes and prevents accidental overwrites when browser sync data is temporarily incomplete
v1.0.2 Bug Fix March 26, 2026

🐛 Fixes

  • Sync Storage: Fixed chrome.storage.sync chunking for emoji and other non-ASCII text
  • Search and Note Actions: Search, filtering, note actions, and import/export flows are more reliable in popup and fullscreen
  • Storage and Refresh: Improved storage recovery, badge counts, domain filters, and context menu refresh during startup and sync changes
v1.0.1 Bug Fix March 25, 2026

🐛 Fixes

  • Popup Note Form: Note form no longer closes on filter tab clicks when it contains unsaved text
v1.0.0 Initial Release March 24, 2026

✨ Added

  • Initial Release: NotePin launched with page-based notes you can create, edit, delete, pin, color, and expand inline
  • Popup and Fullscreen Views: Search, domain filtering, sorting, and note previews are available in both compact and full-page layouts
  • Sync and Drafts: Notes sync across devices and support import/export plus draft autosave
  • Quick Actions: Save selected text from the page context menu, view badge counts for the current site, and use copy, undo delete, and keyboard shortcuts
  • Design and Accessibility: Includes automatic dark mode, smart dates, shared theme variables, Lucide icons, and accessibility improvements
