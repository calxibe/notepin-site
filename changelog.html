What changed, and when.

Every release of NotePin, newest first — what was added, what was fixed, and what was improved.

v1.0.19

Update August 2026

✨ Added

  • Quick Edits in the Note Viewer: Popup and fullscreen note viewing now include a centered Quick Edit action between Copy and Close, then return to the read-only view after saving
  • Clickable Links in Notes: Web addresses written inside note text are now clickable from the note viewer and open in a new tab

🐛 Fixes

  • Smooth Note Updates: Popup and fullscreen no longer fade and rebuild the entire note list after edits, pinning, bulk actions, deletes, undo, filtering, sorting, or sync updates. Cards now update in place while preserving the visible note, scroll position, selection, and keyboard focus
  • Compact Popup Quick Editing: Quick-edit textareas in the popup now use a compact height instead of filling the note viewer
  • Cleaner Notes Without Links: Notes without a saved URL now start at the top of the card beside the timestamp instead of leaving an awkward empty row, in both popup and fullscreen

v1.0.18

Update August 2026

✨ Added

  • Notes Know Which Page They Came From: Every new note now stores the page title, so cards show a readable page name instead of a raw address — and you can search for it
  • Tags: Add up to five tags to any note, click a tag chip to filter, or search tag:research
  • Name Your Colors: Give each of the eight colors your own meaning in Settings — the names show up on swatches, filters, and in-page stickies
  • Storage Meter: Settings now show how much of your browser sync budget your notes use, and warn you before you run out instead of failing on save
  • Light and Dark, Your Choice: Pick Match system, Light, or Dark instead of always following your operating system
  • More Ways to Capture: Right-click any page or any link to save it, not just selected text
  • Real Keyboard Shortcuts: Assign shortcuts to open NotePin, open the board, or save the selection — plus quick keys on the board for search, new note, pin, and moving between notes
  • Markdown and CSV Export: Take your notes to Obsidian, Notion, or a spreadsheet, and restore a backup outright with the new replace-on-import mode

🐛 Fixes

  • Your Notes Cannot Vanish From a Sync Hiccup: A missing internal bookkeeping record could cause NotePin to clear its stored notes and show an empty list. It now rebuilds that record from your notes instead
  • Privacy Settings No Longer Rewrite Old Notes: Turning on URL trimming used to strip links from every existing note the next time you touched any note. It now applies only to notes you save or edit, exactly as the setting says
  • Bulk Actions Tell You What They Will Touch: A selection can include notes hidden by your filters — the toolbar and the delete confirmation now say how many, and Escape clears the selection
  • Nothing You Typed Disappears Silently: Closing a note dialog or the sticky-note editor with unsaved text now asks first, a right-click capture adds to an unsaved draft instead of replacing it, and an edit in progress survives a note changing on another device
  • Every Language Is Complete Again: Bulk selection and duplicate cleanup were showing English text in all six translated languages
  • Stickies Stay Out of Your Printouts: In-page sticky notes no longer appear when you print a page or save it as PDF, show translated color names, and can always be dismissed for a site

⚡ Improved

  • Much Faster Saving: Saving a large note collection went from roughly half a second of lag to a few milliseconds
  • Clearer to See and Use: Visible keyboard focus, better light-mode contrast, screen readers can finally read your note text, reduced-motion is respected, pinned notes are obvious again, and the popup fits more notes on screen
  • Board Fixes: The filter sidebar collapses on narrow or zoomed windows, the bulk toolbar stays in view while scrolling, and an empty board tells you which filters caused it with one button to clear them
  • A Gentler Contact Handoff: Contact links now stay on NotePin first, explain that FixQuotes develops the extension, and open the FixQuotes contact form only when you choose to continue

v1.0.17

Update June 2026

✨ Added

  • A Friendly Nudge for Reviews: Long-time users who actively take notes now see a one-time, dismissible prompt to rate NotePin or share feedback — it only appears after you have used NotePin for a while and never nags again once answered

🐛 Fixes

  • Notes Stop Disappearing Across www and Subdomains: The current-site filter, toolbar badge, and in-page sticky notes now treat www, the main domain, and its subdomains as the same site, so a note saved on www.example.com still shows up on example.com
  • Tidier Note Timestamps: Notes without a saved link now show their time on a clean row instead of an overlay that could overlap long timestamps

🔄 Changed

  • Easier-to-Tap Controls: Larger header buttons, color swatches, and note actions, with clearer keyboard focus highlights throughout
  • Cleaner Popup & Wider Layout Support: Flatter, calmer popup panels and a fullscreen sidebar that adapts better to mid-size and tablet screens

v1.0.16

Bug Fix April 2026

🐛 Fixes

  • Quieter Badge Updates: NotePin now handles tabs that close during background badge refreshes, avoiding repeated service worker errors

v1.0.15

Update April 2026

✨ Added

  • Fullscreen Bulk Workflows: The fullscreen board now supports selecting visible notes, applying colors, pinning or unpinning, exporting selected notes, deleting selected notes with undo, and cleaning duplicate notes
  • Smarter Page Stickies: In-page sticky notes now remember position and collapsed state per site, include a compact note filter, and let you hide the overlay for the current site temporarily
  • Local Preview Harness: Popup, fullscreen, welcome, and edit pages can now be inspected outside the extension runtime with a lightweight mocked chrome.* API

🔄 Changed

  • More Resilient Settings: Settings now open immediately with cached values when the background runtime is unavailable, then show a warning instead of blocking the modal
  • Cleaner Fullscreen Onboarding: The first-run empty state now points to the fullscreen New Note button
  • Compact Bulk Color Picker: Bulk color actions now use a custom dropdown instead of an always-visible swatch row
  • Quieter Sticky Controls: Sticky search and hide-site controls stay hidden until the current site has at least five matching notes

🐛 Fixes

  • Safer Undo Restore: Restoring deleted notes now skips IDs that already exist, avoiding duplicate notes after sync or race-condition restores
  • Documentation Sync: Popup documentation now matches the current search-first filter layout with the Current Site checkbox

v1.0.11

Update April 2026

✨ Added

  • Optional Page Stickies: You can now turn on in-page sticky notes in Settings to show matching NotePin notes directly on supported websites
  • Dedicated Sticky Editor: Each page sticky now includes a quick edit button that opens its own focused editor window, so you can update a note without hunting for it in the popup
  • Drag To Corners: Page stickies can now be dragged to any screen corner and will remember the last corner you used on that site

🔄 Changed

  • Permission On Demand: NotePin now asks for website access only when you enable the new in-page sticky notes feature, and the toggle now stays enabled after you allow access
  • Page-Specific Stickies: You can now keep a sticky note tied to one exact page instead of every page on the same site
  • Simpler Note Browsing: Popup filtering now uses a simpler search-first layout with a Current Site toggle, and clicking note text opens the full note view directly
  • Consistent Sticky Appearance: Page stickies now keep NotePin's own typography on heavily styled sites instead of inheriting the page's fonts

🐛 Fixes

  • No Reload Needed: Page stickies now appear on tabs that were already open when you enable the feature, and they disappear right away when you turn the feature off
  • Better Sticky Reliability: Sticky notes now do a better job remembering their expanded state, updating on SPA-style navigation, and recovering cleanly after reloads or interrupted drags
  • Editor Sync: The popup and dedicated editor now stay in sync after you save in either place, so you always see the latest note content
  • Clearer Empty States: Search and Current Site views now explain whether there are no notes yet or just no matches for your current filter

Update April 2026

  • Quick Copy: Every note card now includes a copy-to-clipboard button with success and error notifications when NotePin writes to the clipboard
  • Fullscreen Help: Fullscreen now includes an in-app Help & FAQ modal with quick answers and a large Feedback & Issues button

🔄 Changed

  • Browser Language: NotePin now follows Chrome's UI language for English, Spanish, Brazilian Portuguese, French, German, Japanese, and Norwegian Bokmål, with English as the fallback when your browser language is not supported
  • Uninstall Feedback: Removing NotePin now opens a short feedback form so you can share why the extension did not fit your workflow
  • Website Gallery: The screenshot preview section now gives popup and fullscreen captures a larger featured layout and uses the full-size images directly so the denser views stay readable before you open the lightbox

  • Expand Toggle: The fullscreen expand-all button now stays available whenever the current view includes notes long enough to collapse, and only hides when every visible note already fits within two lines

🐛 Fixes

  • Norwegian Chrome: Chrome profiles using Norwegian locale variants now pick up the localized Bokmål NotePin interface instead of falling back to English
  • Popup Draft Restore: Draft text now comes back the next time you open the popup if you closed it by mistake
  • Popup Settings Scroll: The popup settings modal now scrolls when its content is taller than the popup

  • Unsaved Draft Warning: Fullscreen now warns before you close the tab if a new note is still unsaved

  • Status Placement: Shared success and error notifications now appear centered at the top instead of pinned to the right edge
