Changelog

All notable changes to NotePin are documented here.

v1.0.11 Update April 2026

✨ Added

  • Optional Page Stickies: You can now turn on in-page sticky notes in Settings to show matching NotePin notes directly on supported websites
  • Dedicated Sticky Editor: Each page sticky now includes a quick edit button that opens its own focused editor window, so you can update a note without hunting for it in the popup
  • Drag To Corners: Page stickies can now be dragged to any screen corner and will remember the last corner you used on that site

🔄 Changed

  • Permission On Demand: NotePin now asks for website access only when you enable the new in-page sticky notes feature, and the toggle now stays enabled after you allow access
  • Page-Specific Stickies: You can now keep a sticky note tied to one exact page instead of every page on the same site
  • Simpler Note Browsing: Popup filtering now uses a simpler search-first layout with a Current Site toggle, and clicking note text opens the full note view directly
  • Consistent Sticky Appearance: Page stickies now keep NotePin's own typography on heavily styled sites instead of inheriting the page's fonts

🐛 Fixes

  • No Reload Needed: Page stickies now appear on tabs that were already open when you enable the feature, and they disappear right away when you turn the feature off
  • Better Sticky Reliability: Sticky notes now do a better job remembering their expanded state, updating on SPA-style navigation, and recovering cleanly after reloads or interrupted drags
  • Editor Sync: The popup and dedicated editor now stay in sync after you save in either place, so you always see the latest note content
  • Clearer Empty States: Search and Current Site views now explain whether there are no notes yet or just no matches for your current filter
v1.0.10 Bug Fix April 2026

🐛 Fixes

  • Sharper Button Labels: Popup, fullscreen, and welcome-page buttons now render text more crisply on Windows by using the bundled bold face and avoiding the soft hover shift that could blur labels
v1.0.9 Bug Fix April 2026

🐛 Fixes

  • Long Note Editors: Popup keeps long drafts under control inside the popup, fullscreen textareas auto-grow, inline editing temporarily removes the note card height cap, and textareas now shrink back down correctly after you shorten a note
v1.0.8 Update April 2026

✨ Added

  • Color Filters: Fullscreen now lets you filter notes by one or more colors and combine them with domain filters for tighter review passes

🔄 Changed

  • Smarter Filter Sidebar: The No Domain filter now sits directly under All Notes with a clearer icon, and selected colors stand out more clearly
  • Dark Mode Contrast: Active filters and the fullscreen New Note button are easier to read in dark mode

🐛 Fixes

  • Filter Reliability: Used note colors stay visible in the filter list, and imported notes now reopen the full board view so they are easier to review right away
  • Sidebar Layout: The domain list now scrolls on its own while the color tray stays pinned at the bottom of the fullscreen sidebar
  • UI Polish: Popup and fullscreen now have sharper button text, proper round action buttons, cleaner empty states, and a more visible scrollbar
  • Safer Recovery: Popup and fullscreen now surface reload, prefill, and import failures more clearly instead of silently dropping the update
v1.0.7 Update April 2026

🔄 Changed

  • Copy Feedback: Inline copy buttons now turn green with a checkmark for 3 seconds after a successful copy
  • Website Navigation: The site header now collapses into a burger menu on mobile so the main pages stay easy to navigate on smaller screens
  • Filter Guidance: Fullscreen empty states and Help & FAQ copy now explain the new color-filter workflow instead of treating colors as visual-only labels

🐛 Fixes

  • Filter Header Spacing: Fullscreen filter section headings now keep the intended spacing above the color and domain lists
  • New Note Cancel: Canceling a fullscreen draft now clears it immediately so it does not reopen unexpectedly or keep the refresh warning around
  • Popup Handoff: Sending a draft from popup to fullscreen now moves it cleanly, so canceling fullscreen does not leave the old draft waiting back in popup
  • Reloaded Drafts: Fullscreen now ignores stray browser-restored New Note values unless NotePin actually saved a draft to restore
  • Bulk Clear: Clearing every visible note in fullscreen now works reliably even after importing larger note collections
  • Release Packaging: The build now flags reserved and system-generated files such as _metadata before creating the upload zip, so packaging issues show up locally instead of during upload
  • Website Contrast: Dark-mode secondary text is now brighter, especially in changelog details and other supporting copy
v1.0.6 Update April 2026

✨ Added

  • Quick Copy: Every note card now includes a copy-to-clipboard button with success and error notifications when NotePin writes to the clipboard
  • Fullscreen Help: Fullscreen now includes an in-app Help & FAQ modal with quick answers and a large Feedback & Issues button

🔄 Changed

  • Browser Language: NotePin now follows Chrome's UI language for English, Spanish, Brazilian Portuguese, French, German, Japanese, and Norwegian Bokmål, with English as the fallback when your browser language is not supported
  • Uninstall Feedback: Removing NotePin now opens a short feedback form so you can share why the extension did not fit your workflow
  • Website Gallery: The screenshot preview section now gives popup and fullscreen captures a larger featured layout and uses the full-size images directly so the denser views stay readable before you open the lightbox
  • Shared Settings: Popup and fullscreen now use the same settings modal, with popup size and fullscreen sort moved to the top, import/export kept fullscreen-only, popup size presets previewing live, and settings saving as soon as you change them
  • Fullscreen Header: Header action icons are larger for easier scanning and clicking, and the old direct report button is now a help entry point with the feedback form one click away
  • Clear Placement: The fullscreen clear button now sits right-aligned below the note list and only shows when the current view has more than five notes
  • Expand Toggle: The fullscreen expand-all button now stays available whenever the current view includes notes long enough to collapse, and only hides when every visible note already fits within two lines

🐛 Fixes

  • Norwegian Chrome: Chrome profiles using Norwegian locale variants now pick up the localized Bokmål NotePin interface instead of falling back to English
  • Popup Draft Restore: Draft text now comes back the next time you open the popup if you closed it by mistake
  • Popup Settings Scroll: The popup settings modal now scrolls when its content is taller than the popup
  • Settings Modal: Fixed a shared settings error that could block the modal from opening in popup or fullscreen
  • Unsaved Draft Warning: Fullscreen now warns before you close the tab if a new note is still unsaved
  • Fullscreen Expand Toggle: Fixed browsers where line-clamped note text could keep the fullscreen expand-all button hidden or make it disappear after expanding everything
  • Status Placement: Shared success and error notifications now appear centered at the top instead of pinned to the right edge
v1.0.5 Bug Fix April 2026

🐛 Fixes

  • Draft Handoff: Opening fullscreen while you are still writing in the popup now carries that in-progress note across instead of starting blank
  • Draft Context: The transferred draft now keeps its selected color and pre-fills the page URL when NotePin can read the current site
v1.0.4 Update April 2026

✨ Added

  • Privacy Settings: You can now strip query strings and hash fragments from newly saved note URLs

🔄 Changed

  • Context Menu Flow: Saving selected text from the page context menu now opens NotePin with the text prefilled so you can review it before saving
  • Shared UI Refresh: Popup and fullscreen now share a more polished UI layer, and fullscreen works better on narrower screens
  • Save and Sync Feedback: Save and sync handling is more reliable and now surfaces clearer non-blocking feedback when sync has problems

🐛 Fixes

  • Bare URL Entry: Note URL fields now add https:// automatically for bare web addresses while still rejecting incomplete URLs
  • Missing Domain Filter: Fullscreen domain filters now include a No Domain option when saved notes do not have a domain
  • Search Feedback: Popup and fullscreen now show the exact search term when no notes match
  • Source URL Retention: Notes started from the page context menu now keep the original page URL and domain when saved from the popup
  • URL Validation: Invalid or unsupported page URLs are no longer attached to new notes or context-menu prefills
  • Accessibility: Improved keyboard and screen-reader support for note controls and status announcements
  • Mobile Layout and Startup: Fixed mobile fullscreen and popup issues affecting viewport sizing, header and footer layout, scrolling, and first-load stability
  • Search Control Borders: Popup and fullscreen search inputs now render cleanly as a single control
